# 铁律与反模式（踩坑记录）

这一页比图值钱。每条都是实际迭代中被用户判过"不行"之后修正的。
**做这套风格时先读这页，再动笔。**

---

## 铁律（12 条）

1. **边框就是墨本身，不是浅灰。** 面板线 `#0d1117`。曾把线色定成 `#d5dde6`，
   被用户判"不像" —— 浅灰边框是"浅色模式"，不是印刷品。
2. **圆角归零、柔光投影归零。** 唯一的"立体"是错版硬边（2~3px offset 实心墨影）。
3. **印刷品不发光。** 悬停 = 墨框加粗一档 / 硬投影位移；禁止 translateY 浮起 +
   box-shadow 柔光那套玻璃拟态。
4. **彩色只在虹带。** 纸/墨/淡墨之外的所有彩色都是虹带三色（+高危反相区小块）。
   功能色（ok/warn/bad）是"读数"，不算装饰彩，但必须在纸底上可读（深一档）。
5. **渐变只属于虹带。** 标题不渐变填色（印刷品没有渐变文字）；标题的识别靠
   墨黑字 + 墨色下划线/标尺。
6. **反相区用独立命名的变量（--inv-*），绝不让两个变量互指。**
   CSS 变量没有交换语义：写 `--paper:var(--ink); --ink:#f4f6f9` 时，
   后一条生效后 `--paper` 拿到的是**已经变成纸色的 --ink**，整个反相翻不过来
   （实测：反相区渲染成白底，只有标题是黑的）。
7. **读数不许说谎。** 反相只改容器配色；ok/idl/bad 三态判定与文案一个字不动。
8. **母题以参数化生成为主，位图贴片为辅。** 固定分辨率贴片一到别的尺寸就露馅。
9. **描摹 SVG 只当形状参考。** vtracer 描出来的件曲线有零点几像素抖、细线
   （<2px）偶尔被 filter_speckle 吃掉。生产用参数化生成器重写（motifs.md）。
10. **每个母题限量使用。** 大×全页只此一枚；粗黑条只跟分区标题；不到处撒。
11. **空状态 ≠ 失败。** 虚线圆弧是中性淡墨，绝不染红。
12. **文字标是槽位文本。** `编号;` / `署名;`（如 `_B42`、`DESIGN BY WyHXnR;`）
    是可替换内容，不是固定图形。

## 反模式（做过且被否决的，别重复）

| # | 想法 | 为什么不行 |
|---|---|---|
| A1 | 只换变量底色，保留圆角/玻璃/柔光/渐变标题 | 得到的是"浅色模式"，不是一套设计。**这是最深坑的一条** |
| A2 | 虹带第一版：6 段硬色标拼接 | 视觉是六个色块，接缝硬 |
| A3 | 虹带第二版：13 停靠点单向光谱 | 结构错 —— 参考图是双向不对称的 |
| A4 | 虹带第三版：5 条细线 | 细到看不出来，且错开得像散落划痕 |
| A5 | X 阶梯第一版：两层 45° linear-gradient 交叉画实心 X | 笔画粗细靠 40%~60% 猜，出来的 X 一大一小两坨 |
| A6 | X 阶梯第二版：实心 X + 虚线方块 rotate(45deg) | 两个元素尺寸不一致（6×15 与 11×11），旋转后实际占位不同，**压在一起糊成一团**（用户原话："总览前面那俩×可能重叠了"） |
| A7 | 沿 90° 切虚线画 X | X 被切成两根竖条 |
| A8 | 粗黑条三连挂分区标题外层 + margin-left:auto | 被 flex-wrap 甩到下一行，和右侧开关撞在一起 |
| A9 | 虹带画在 header::after | nav.toc 是 sticky + z-index:20，直接压在 header 底边上，彩条两头被吃掉，只剩中段 |
| A10 | 空心方块当"空心圆"用 / "四边虚线去掉下边"当半圆 | 出来是直角缺口，像没画完的角标。真半圆用 `border-radius:30px 30px 0 0` |
| A11 | 状态点用圆点 + 光晕 | 印刷符号里没有圆点。改方块 + 墨框 |
| A12 | 反相区里按钮/输入框忘记翻底色 | 浅底浅字，打字看不见（2026-10-13 用户现场抓到） |

## 验收自查（交付前过一遍）

- [ ] 面板线是墨色实线，不是浅灰
- [ ] 全页找不到一个非零圆角（胶囊/圆按钮/圆点）
- [ ] 全页找不到柔光 box-shadow；硬投影 ≤6px
- [ ] 彩色只出现在：虹带（+ accent 装饰）+ 功能三态 + 高危反相区小块
- [ ] 标题没有渐变填色
- [ ] 大×只此一枚；每个母题都数得过来
- [ ] 反相区（如有）的输入框/按钮/表格全部翻色，三态判定未动
- [ ] 空状态中性色，未染红
- [ ] 数字等宽；读数在白底上对比度足够
- [ ] 键盘 Tab 可达，焦点态可见
- [ ] <620px 不横向滚动、母题不删
